# sinapsi-site

Source of the site at https://sinapsi.insalata-fresca.ch/. A single static page, no build step.

Sinapsi is a personal engineering lab for agentic software delivery. The page is a case study of a platform approach to running AI agents, with the architecture, the control room, the essays and the code.

Related repositories:

- [sinapsi-mcp](https://github.com/insalata-fresca/sinapsi-mcp): the MCP servers and shared libraries.
- [sinapsi-design](https://github.com/insalata-fresca/sinapsi-design): the design essays.
