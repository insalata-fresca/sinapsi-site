# sinapsi-site

Source of the site at https://sinapsi.insalata-fresca.ch/. Static pages, no build step.

Sinapsi is a personal engineering lab for agentic software delivery. The site is a case study of a platform approach to running AI agents:

- `index.html`: the overview, with the four-block architecture (the Sinapsi Dev Factory, the platform of services, applications and governance as code).
- `factory.html`, `governance.html`, `knowledge.html`, `corridor.html`, `data-platform.html`, `control-room.html`: one deep dive each, built around a larger diagram and ending at the essay that argues it.

Related repositories:

- [sinapsi-mcp](https://github.com/insalata-fresca/sinapsi-mcp): the MCP servers and shared libraries.
- [sinapsi-design](https://github.com/insalata-fresca/sinapsi-design): the design essays.
