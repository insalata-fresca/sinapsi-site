Deep dive: the agent corridor

One agent call, start to finish

Every call an agent makes crosses one governed gate. A person is accountable and an agent is not, so an agent never reuses a person's door.

  1. No side doors.One gateway, one identity per agent, one record per call.
  2. Typed by effect.Read, write or secret is declared where the tool lives.
  3. Graduated autonomy.Reversible actions proceed. Stateful ones ask. A short list is never autonomous.
  4. Shadow before enforce.A new layer observes first, on a clock, before it blocks.
